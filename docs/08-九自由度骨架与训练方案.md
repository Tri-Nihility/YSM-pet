# 08 · 九自由度骨架：绑定、重力与站立/行走训练

> 本阶段把 YSM 模型从「动画播放器」改造成「物理受控体」：
> 9 个可控关节 + 重力 + PPO 课程学习（先学站立，再学走路），
> **全程不加载模型自带动画**（`use_native_animation: false` 为硬开关）。

## 1. 9 个可控关节

| 0 | 左肘 | `LeftForeArm` | (-0.258, 1.522, 0.002) | 0 ~ +140 | 屈肘向前 |
| 1 | 右肘 | `RightForeArm` | (+0.258, 1.522, 0.002) | 0 ~ +140 | 屈肘向前 |

## 2. 坐标系与符号（三处共用，勿改）

**模型空间**（YSM 烘焙顶点）：右手系，1 方块≈1 米，`+X`=角色右侧、`+Y`=上、`-Z`=正前方。
实测依据：`LeftArm` 质心 x=-0.244 / `RightArm` +0.244；眼睛·眼睑 z≈-0.21；脚尖 z≈-0.20。

**pybullet 空间**（Z-up）：

```
P = [[0,0,-1],[-1,0,0],[0,1,0]]    # det=+1，纯旋转
pb = P @ model      即 px=-mz(前), py=-mx(左), pz=my(上)
```

**角度符号**（最易错的地方）：

* 关节角 `q`（度）= 绕 `+X_model` 右手正转 → `q>0` = 肢体向前摆。
* 上游 `RotationValue` 对 X/Y 取负：`R = Rz(rz)·Ry(-ry)·Rx(-rx)`，
  所以驱动 YSM 骨骼时 **`rotation.x = -q`**。
* URDF 关节轴在 pb 空间为 `axis=(0,-1,0)`（即 `P@[1,0,0]`）。

已验证：URDF 零位 FK 与模型枢轴逐项对齐（误差 0.000）；左膝 -90° 后小腿指向 -X（向后）✓。

## 3. 物理绑定（`src/phys/bind.py`）

* 11 个分段：pelvis / torso / head / 2×(上臂, 前臂) / 2×(大腿, 小腿)；
  脚掌不在 9 关节内 → **固定焊在小腿末端**，提供支撑面（额外碰撞盒）。
* 根 = pelvis（`AllBody` 枢轴，髋高 1.062），pybullet `useFixedBase=False` → 浮动基。
* 质量：按体段占比表（Winter 生物力学）人工标定共 51.8 kg；
  ~~按方块体积自动分配~~会失败——头发/裙摆是空心薄壳，AABB 累加让头部占 39%，
  头重脚轻根本学不会站立（配置里保留 `auto_from_volume` 开关做对照）。
* 惯性/碰撞：每段用其方块 AABB 转成 box（惯性 + 碰撞体）。
* 产物：`models/ysm_atri_9dof.urdf`、`data/processed/skeleton9.json`。

## 4. 环境（`src/env/stand_walk.py`）

* 重力 -9.81 m/s²（`configs/phys.yaml`），物理 120 Hz，控制 30 Hz（frame_skip=4）。
* 动作：9 维 `[-1,1]` → 限位内目标角 → pybullet `POSITION_CONTROL`（PD，力矩上限来自配置）。
* 观测 39 维：髋高、局部线速度/角速度、躯干 up 向量、9 关节角(归一化)、9 关节速度、
  双脚触地、上一步动作；walk 阶段 +目标速度 = 40 维。
* 课程（`configs/phys.yaml → curriculum`）：
  * **stage1 stand**：存活 +1/s，站高奖励，躯干直立奖励，重心压在支撑面内；
    倒下（髋高 < 0.92×站高 或 倾角 > 45°）一次性 -20。
  * **stage2 walk**：前进速度奖励 `min(v, 1.2·v_target)`，左右脚交替触地奖励；
    热启动：加载 `stand_final.pt`。
* 域随机化：质量 ±10%、地面摩擦 0.7~1.0、初始推挤 0.15 m/s。

## 5. 训练（`src/train/ppo.py` + `scripts/train.py`）

自写轻量 PPO：MLP 2×64 tanh + 状态无关 log_std + GAE(λ) + clip，
无任何 RL 框架依赖，纯 CPU（torch 2.x cpu 版）。

```
python scripts/train.py --stage stand --iters 250 --steps-per-update 4096
python scripts/train.py --stage walk  --iters 300 --warmstart outputs/checkpoints/stand_final.pt
```

产物：`outputs/checkpoints/{stage}_{final,best}.pt`、`outputs/logs/{stage}_train.csv`、
`{stage}_curve.png`。基准速度 ≈ 8.5 s/迭代（4096 步）。

## 6. 表情接口（预留，`src/ysm/expression.py`）

YSM 的表情是**显隐**而非形变：并列骨骼用 `scale=(0,0,0)` 隐藏。
接口为「槽位 + 互斥选项」（`configs/expressions.yaml`）：

```python
rig = ExpressionRig(model)
rig.set_slot("mouth", "m11")   # 17 种嘴型 / 2 套脸 / 2 套眼 / 眉 / 眨眼
anim = rig.to_anim()           # -> {bone: {"scale":[0,0,0]}} 叠加进姿态字典
```

训练不碰表情；GUI 面板每个槽生成一排按钮。渲染端把每根带网格骨骼拆成
独立 primitive，显隐 = `mesh.visible`，与 YSM 语义一一对应。

## 7. TypeScript GUI（`web/`）

* 技术栈：Vite + React 18 + TypeScript + three.js。
* 渲染：模型导出为带蒙皮的 `model.glb`（215 个刚性 primitive，IBM=T(-piv)，
  顶点权重=所属骨骼 1.0，见 `src/export/gltf_export.py`），浏览器 GPU 蒙皮，~30fps。
* 面板：训练控制（阶段/开始/暂停/停止/热启动/奖励曲线）、9 关节滑块摆 pose、
  表情槽位按钮、WS 状态条。
* 后端：`src/serve/server.py`（FastAPI + uvicorn，端口 8765），
  WebSocket `/ws` 30Hz 推送关节角 + 骨盆位姿；训练线程与 GUI 同进程。

```
# 构建 GUI
cd web && npm install && npm run build
# 启动（托管 dist + API + WS）
cd src && python -m serve.server          # http://127.0.0.1:8765
```

角度桥接（前端）：`bone.rotation.x = -q°`（three.js Object3D 的 TRS 组合
`T·R·S` 与蒙皮链 `G·IBM` 推导等价于上游 FK）。

## 8. 已知边界

* 关节全部单轴（绕 X）。双轴髋/肩需要扩 `axis` 支持多分量再推两个维度。
* URDF 无自碰撞（pybullet 默认关闭 URDF_USE_SELF_COLLISION）。
* 走路阶段尚未调出稳定步态——奖励项 `contact_alternation` 较弱，
  可考虑加步频相位先验或脚部落点奖励。
* `ysmbin.py` 仍只支持 format ≤ 15。
