## pybullet 的特殊之处（重要）

pybullet **不是**用 pip 正常装上的：

- PyPI 上的 pybullet 只有 Linux wheel，Windows 装会报
  `Microsoft Visual C++ 14.0 or greater is required`（需本地编译 C++ 引擎）
- 实际做法：从 conda-forge 取 win-64 预编译包
  `pybullet-3.25-py313h290c699_5.conda`，解包后手动放入 site-packages
- 其依赖 `zlib.dll` 系统缺失，已从 conda-forge `libzlib` 补到 venv 根目录与 site-packages

**后果与注意事项**：

- `pip list` 里显示的是 `pybullet 3.2.5`（conda 版本号与 PyPI 的 3.2.7 不同，正常）
- **不要跑 `pip install pybullet` 或 `pip uninstall pybullet`** —— 前者会失败，
  后者可能删掉手动放的文件导致 import 崩
- 若 pybullet 突然 `ImportError: DLL load failed`，先确认
  `C:\Users\User\.workbuddy\binaries\python\envs\default\zlib.dll` 还在
- `pybullet_envs` 需要 `gym`（未装），本项目不用它，只用核心 `pybullet`

> 重装流程已沉淀为技能 `windows-no-wheel-install`，需要时可复用。

## CPU 训练注意事项

- 跑训练前设线程数，避免默认占满所有核：
  ```python
  import torch; torch.set_num_threads(4)
  ```
- 数据加载 `DataLoader` 的 `num_workers` 建议 0（Windows 多进程 + 小数据反而慢）
- 优先用小 batch 多步累积，而不是大 batch（内存更省）
- 期望：小模型几小时内能看到收敛迹象；跑不动就先砍数据量做单类过拟合
