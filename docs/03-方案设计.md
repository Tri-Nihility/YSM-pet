# 03 方案设计

## 1. 模块职责

| 模块 | 职责 | 不负责 |
|---|---|---|
| `src/data` | 读原始动捕/YSM 动画 → 重定向 → 归一化 → `Dataset` / `DataLoader` | 模型 |
| `src/models` | 运动模型本体（条件编码、序列生成、FK 层） | IO、训练循环 |
| `src/train` | 训练循环、损失、优化器、checkpoint、日志 | 数据解析 |
| `src/eval` | 指标计算、pybullet 可视化、滑步检测 | 训练 |
| `src/export` | 张量 → YSM 动画文件 | 训练、评估 |
| `configs` | 骨骼定义、映射表、超参 | 逻辑 |
| `scripts` | 一次性批处理（数据下载、批量转换） | 被 import |

## 2. 模型路线选型

| 路线 | 代表做法 | 优点 | 代价 | CPU 可行性 |
|---|---|---|---|---|
| **自回归（推荐先做）** | Transformer decoder / GRU，逐帧预测下一姿态 | 简单、可流式生成、易调试 | 长序列易漂移 | ✅ 可行 |
| **扩散（MDM 类）** | 对整个序列去噪 | 质量高、多模态 | 训练慢、显存吃紧 | ⚠️ 小模型勉强 |
| **VAE** | 编码到隐空间再解码 | 训练快、可插值 | 易模糊、多样性差 | ✅ 可行 |
| **RL + 物理（DeepMimic 类）** | pybullet 环境中模仿参考动作 | 物理合理、不滑步 | 调参极重、收敛慢 | ❌ 不现实 |

**建议路径**：自回归 Transformer 先跑通端到端（验证数据 + 导出链路），
拿到 baseline 指标后再决定是否上扩散。

### 基线规模（CPU 友好）

```
seq_len      60~120 帧
d_model      128 ~ 256
n_layers     2 ~ 4
n_heads      4
batch_size   16 ~ 32
参数量       1M ~ 5M
```

先用 1 个动作类别（walk）单类过拟合，确认模型能记住并复现，再扩到多类。
**单类过拟合是性价比最高的排错手段**，能一次性暴露数据管线、归一化、损失的问题。

## 3. 损失函数

| 项 | 作用 | 权重（初始建议） |
|---|---|---|
| 旋转重建 L1/L2 | 主目标，`local_rot` 直接回归 | 1.0 |
| FK 后关节位置误差 | 防止局部角度误差在末端被放大（手/脚最明显） | 0.5 |
| 根速度误差 | 保证位移与朝向合理 | 0.5 |
| **足部滑步惩罚** | 接触帧脚的水平速度 → 0，消除"滑冰" | 0.1 |
| 骨长一致性 | 罚 FK 后骨长偏离 T-pose | 0.01 |
| 平滑度（jerk） | 罚相邻帧加速度突变，去抖动 | 0.01 |

> 滑步惩罚和骨长一致性是"看起来像真的"和"数学上误差小"的分水岭，别省。

## 4. 评估指标

| 指标 | 含义 | 目标 |
|---|---|---|
| MPJPE | FK 后所有关节平均位置误差 | 越低越好 |
| 关节角度误差 | 旋转本身的误差（度） | 越低越好 |
| **Foot skating** | 接触帧脚位移量 / 总位移 | 关键主观指标 |
| 抖动度 jerk | 三阶差分均值 | 越低越平滑 |
| 多样性 | 同条件下多次采样结果的方差（生成式才有） | 生成式路线关注 |

数值指标之外，**必须过一遍 pybullet 可视化**：
指标好看但动作诡异的情况非常常见（尤其中间帧）。

## 5. pybullet 在本项目中的角色

pybullet 已装好（conda-forge win-64 版本 3.2.5）。本项目用它做三件事：

1. **可视化检查**：把生成的骨架序列驱动到一个简易人形上，肉眼看是否自然
2. **物理合理性校验**：检测穿地、浮空、重心失衡
3. **接触标签生成**：用真实接触信息产生 `foot_contact`，比速度阈值准

⚠️ pybullet 是**评估与辅助工具**，不是训练主力（RL 路线在 CPU 上不现实）。

## 7. 风险点

| 风险 | 影响 | 缓解 |
|---|---|---|
| YSM 骨骼/动画格式不明 | 导出无法进行 | 尽早拿到一份 YSM 模型与动画样本 |
| CPU 训练太慢 | 迭代周期长 | 小数据小模型；单类过拟合先验证 |
| 重定向失真 | 动作变形 | FK + 骨长单测兜底，不靠肉眼 |
| 自回归长序列漂移 | 长动画越走越歪 | 限制生成长度；必要时加周期性约束 |
