# YSM-pet 依赖清单
#
# 桌宠运行必需（源码方式跑才需要；GitHub Release 里的打包版已内置，无需安装）：
#   PySide6      窗口 / 渲染呈现
#   numpy scipy  几何与矩阵运算
#   pyyaml       configs/joints9.yaml
#   tqdm         进度条
#   Pillow       贴图处理
#   py7zr        .7z 格式的模型压缩包（缺少会静默降级到系统 tar，不够稳）
#   zstandard   **加密格式 .ysm 的 zstd 解压**（ysmcrypt.decrypt_ysm_file 走它）。
#                漏了它在源码环境不报错（py7zr 不会带它进来），但 PyInstaller
#                按 requirements+import 分析，漏列 → 打包版一加载加密模型就是
#                ModuleNotFoundError: No module named 'zstandard'（v0.3.0 事故）。
#   backports.zstd  py7zr≥1.1 解 zstd 压缩的 7z 时需要（Python<3.14 的
#                compression.zstd 替代）。缺了只影响 zstd 压缩的 7z 模型包。
#   PyInstaller  仅本地打包 exe 时需要（CI 里另行安装）
#
# ⚠️ 已从旧版 YSM-Motion 移除的两个依赖，别再捡回来：
#   torch    训练线遗产。桌宠是纯动画播放器，一行 torch 都不用，
#            带上会让打包产物从 ~200MB 膨胀到 ~2GB。
#   pybullet 只为两个相机矩阵函数服务（computeViewMatrixFromYawPitchRoll /
#            computeProjectionMatrixFOV），已被 `src/pet/camera.py` 用纯
#            numpy 复刻（数值已对齐到 1e-7）。移除它的关键原因：
#            **pybullet 在 PyPI 上没有 Windows 轮子**，`pip install pybullet`
#            会退回源码构建并失败 —— CI 根本装不上。
